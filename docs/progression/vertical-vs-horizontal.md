# Vertical vs Horizontal Progression

Sanguine Archipelago separates numerical competence from expressive mastery.

## Vertical Progression

Vertical progression increases broad capability.

In this project, vertical progression primarily means:

- Core Check investment
- resource growth
- campaign rank

Vertical progression answers:

> How strong is this character at the broad action?

## Horizontal Progression

Horizontal progression changes what a character can do with competence they already have.

In this project, horizontal progression primarily means:

- Specialty ranks
- specialization nodes
- faction training
- relic permissions

Horizontal progression answers:

> What distinctive mastery does this character express?

## Why Separate Them

If Specialties become flat stats, players treat them as mandatory taxes. If Core Checks are hidden behind techniques, the resolution engine becomes unclear.

Keeping the layers separate creates:

- clearer UI
- healthier advancement choices
- better future faction design
- easier balancing
- stronger character identity

## Reward Philosophy

Vertical rewards should feel like improved capability. Horizontal rewards should feel like new authority over a situation.

Examples:

- Vertical: raise `Guard` because the character has become broadly harder to move, hurt, or overwhelm.
- Horizontal: gain `Brace II` because the character has learned how to absorb impact and control collision consequence.
- Vertical: raise `Broker` because the character now understands institutions more reliably.
- Horizontal: gain a faction unlock that lets the character request Guild inspection seals.

The healthiest progression mixes both layers without letting either consume the other.

## Failure Modes

Watch for:

- vertical-only progression becoming stat inflation
- horizontal-only progression making broad competence feel irrelevant
- faction unlocks becoming stores
- Specialties becoming mandatory taxes for normal actions
- Attribute growth becoming too frequent and flattening identity
