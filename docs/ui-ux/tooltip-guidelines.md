# Tooltip Guidelines

Tooltips provide focused depth. They should not become hidden encyclopedias.

## Rules

- Show the next useful layer of information.
- Keep tooltip text scannable.
- Prefer short labels and compact lists.
- Avoid showing every future rank or system rule at once.
- Lazy-render heavy tooltip content when possible.

## Specialty Tooltips

Specialty tooltips should show:

- description
- current rank
- unlocked effects
- next unlock
- next prerequisite
- related Core Checks

They should not show the full I-IV tree unless the player opens a dedicated future mastery detail view.

## Core Check Tooltips

Core Check tooltips may show:

- formula
- linked Attributes
- roll modifier
- examples

This distinction reinforces the difference between stats and techniques.
