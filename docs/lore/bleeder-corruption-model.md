# Bleeder Corruption Model

Corruption is not only a meter. It is a relationship with power that should feel useful, dangerous, and narratively expensive.

## Mechanical Role

Corruption can support:

- risk-bearing arcane actions
- forbidden relic use
- spiritual contamination
- bargain-like power exchange
- faction suspicion

## Design Principle

Corruption should tempt players because it solves real problems. It should matter because the solution asks for a later cost.

## UI Principle

Corruption effects should be legible before the player chooses them. Avoid surprise punishment that makes the system feel arbitrary.
